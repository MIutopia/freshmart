# 基于 Spring Boot + Vue 的生鲜果蔬配送商城系统

## 1. 建设目标

系统面向消费者、配送员和商城管理员，提供从浏览生鲜商品、下单支付、分拣配送到售后评价的闭环服务。前端建议采用 Vue 3、Vite、Pinia 与 Element Plus；后端采用 Spring Boot、Spring Security、MyBatis-Plus、Redis 与 MySQL，前后端通过 RESTful API 交互。

核心业务特点如下：

- 生鲜商品具有保质期短、库存和规格变化快的特点，需要支持批次、库存预警和上下架管理。
- 订单具有即时履约属性，需要将支付、拣货、配送、签收状态分开维护并可追踪。
- 同一订单的运费、配送时段、优惠与售后均会影响最终结算，需要保留完整金额明细和状态流水。

## 3. 前台功能说明

### 3.1 商品中心

商品按“新鲜蔬菜、水果、肉禽蛋品、水产海鲜、乳品烘焙、粮油调味”分类。商品详情应展示主图、产地、规格、单价、库存、保质期提示、配送说明与评价；对多规格商品，以 SKU 维度维护价格、库存和图片。

### 3.2 购物车与结算

购物车按店铺或配送仓组织商品，实时校验商品是否下架、库存是否充足。结算页选择收货地址、配送日期和配送时间段，计算商品金额、运费、优惠金额与应付金额。提交后生成待支付订单，支付成功再进入待分拣状态。

### 3.3 订单与售后

订单状态建议区分为：待支付、待分拣、配送中、已完成、已取消、售后中、已退款。用户可查看每次状态变更和配送员信息；售后申请需保存问题类型、图片、申请金额、审核结论和退款流水。

## 4. 后台功能说明

### 4.1 商品和库存

管理员维护分类、商品、规格与库存。库存建议以 SKU 为最小扣减单位，订单支付后预占或扣减库存；取消、退款时根据履约状态执行回补。对于易腐商品，可增加入库批次、生产日期、过期日期与临期预警字段。

### 4.2 订单履约与配送

支付完成的订单由仓库进行分拣出库，再指派配送员。配送员更新“已接单、已取货、配送中、已送达”等节点；系统记录操作人、时间和说明，既方便用户追踪，也便于异常订单审计。

### 4.3 营销与数据分析

营销模块管理轮播位、优惠券、满减、限时折扣和推荐位，并在结算时校验有效期、门槛、适用商品和领取限制。数据看板应至少提供日/周/月销售额、订单量、客单价、复购率、热销商品、库存预警和配送准时率。

## 5. 核心实体建议

| 业务域 | 主要实体 |

| 交易 | 购物车、订单、订单项、支付流水、订单状态流水、退款单 |

## 6. 图标资源使用说明

所有图标使用 `currentColor`，可放入 Vue 组件并由 CSS 控制颜色，例如：

```html
<img class="category-icon" src="/assets/icons/vegetable.svg" alt="蔬菜" />
```

```css
.category-icon {
  width: 32px;
  height: 32px;
  color: #1e8e57;
}
```

`fresh-market-logo.svg` 用于网站导航和登录页；`fresh-market-logo-mark.svg` 用于 favicon、移动端 App 图标或窄屏导航。图标文件与建议的业务入口对应如下：

| 文件 | 对应入口 |
| --- | --- |
| `icons/vegetable.svg` | 新鲜蔬菜 |
| `icons/fruit.svg` | 时令水果 |
| `icons/meat.svg` | 肉禽蛋品 |
| `icons/cart.svg` | 购物车 |
| `icons/order.svg` | 我的订单 |
| `icons/delivery.svg` | 配送服务 |
| `icons/location.svg` | 收货地址 |
| `icons/dashboard.svg` | 管理后台数据看板 |
