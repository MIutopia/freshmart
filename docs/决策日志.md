# 决策日志

## ADR-001：GitHub 远程仓库延后连接

- 状态：已接受
- 日期：2026-09-08
- 决策：项目先在本地完成可演示、可验证的功能闭环；达到交付条件后再创建或绑定 GitHub 远程仓库并推送。
- 原因：避免将尚未稳定的架构骨架和未确认的业务规则提前暴露为远程基线。
- 影响：当前提交仅保存在本地版本库，仍可用于阶段性回滚；远程仓库地址、可见性和 GitHub 认证均暂不处理。

## ADR-002：首期交付范围

- 状态：待确认
- 建议：先实现用户浏览和下单、商家商品与订单处理、配送员接单与签收、后台审核与数据概览四条主链路；AI 以导购与订单问答两项只读能力进入首期。
- 需确认：是否接受该 MVP 范围，或需要将支付、地图导航、优惠券、退款中的任一项提前纳入首期。
