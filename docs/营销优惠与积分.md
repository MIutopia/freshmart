# 营销优惠与积分

营销规则由商家库保存，支持优惠券、满减、会员等级、积分和秒杀五种类型。每条规则必须包含生效时间、失效时间、规则 JSON 和是否可叠加标记；管理员后续可增加平台级规则。

统一优惠计算顺序为：会员折扣、按优先级执行的固定优惠，再按可叠加标记累加；总优惠不得超过商品金额，应付商品金额不得小于 0。配送费仍按优惠后商品金额计算。

当前阶段已提供商家创建营销规则和优惠券接口、管理员会员等级接口、用户优惠券领取与会员查询接口，并覆盖叠加优惠与非法会员折扣率测试。下单时后端读取用户可用优惠券和会员积分，按商家子订单计算折扣并写入交易/订单价格快照；优惠券在下单时预占、支付成功时核销、15 分钟超时释放。积分在支付成功后按实付金额发放并以交易号幂等。秒杀库存扣减、退款积分回退和营销数据看板后端已具备；积分抵扣尚未接入下单应付金额计算，积分兑换规则和前端入口仍待实现。
