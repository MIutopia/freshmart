# 配送区域与骑手工作台

固定配送区域由管理员在 `freshmart_delivery.delivery_zones` 中管理。商家仓库创建时只接收状态为 `ACTIVE` 的区域 ID，因此停用区域后无法再新增仓库绑定。

配送员的账号来自 `freshmart_user.users`，配送员档案、任务和绩效数据位于 `freshmart_delivery`。配送员接口以当前 Bearer Token 的 `user_id` 查询任务和绩效，不允许指定其他配送员 ID。

当前阶段提供区域管理和配送员工作台。管理员可按配送区域派单；骑手必须在默认 5 分钟内接单，随后依次确认取货、上传送达凭证。接单超时的任务每 60 秒回到派单池，并增加骑手超时绩效；每日统计记录分配、接单、送达、超时和准时率。一个商家子订单只生成一个配送任务。
