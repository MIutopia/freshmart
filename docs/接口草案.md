# 接口草案

接口统一返回 `code`、`message`、`data`、`traceId`，写操作支持 `Idempotency-Key` 请求头。

| 领域 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |
| 认证 | POST | `/api/auth/login` | 登录并返回访问令牌 |
| 认证 | POST | `/api/auth/logout` | 吊销当前 Bearer Token 会话 |
| 认证 | GET | `/api/auth/me` | 查询当前登录用户和角色 |
| 商品 | GET | `/api/catalog/products` | 公开查看已上架商品，可按 `categoryId` 筛选并返回可售克数 |
| 商品 | GET | `/api/catalog/products/{skuId}` | SKU 详情和实时库存 |
| 仓储 | GET | `/api/merchant/warehouses` | 商家查询自己的仓库与固定区域 |
| 仓储 | GET | `/api/orders/{orderId}/traceability` | 查询订单项、仓库和实际出库批次 |
| 购物车 | PUT | `/api/carts/items` | 添加或更新购物车项 |
| 订单 | POST | `/api/orders` | 校验价格、库存并创建待支付订单 |
| 交易 | POST | `/api/trades` | 按商家生成子订单并创建 15 分钟库存预占；需 `Idempotency-Key` |
| 交易 | GET | `/api/trades/{tradeNo}/payment-code` | 读取模拟支付码或本地测试用个人收款码展示信息 |
| 订单 | GET | `/api/orders/{orderId}` | 查询订单和状态流水 |
| 订单 | GET | `/api/orders` | 消费者查看本人、商家查看所属、管理员查看全部子订单 |
| 支付 | POST | `/api/payments/{tradeNo}/prepay` | 首期默认创建模拟支付单；个人收款码仅支持人工确认的本地测试 |
| 支付 | POST | `/api/admin/payments/{tradeNo}/confirm-personal-wechat-qr` | 管理员人工核验个人收款到账后确认，扣减预占库存并创建配送任务 |
| 支付 | POST | `/api/payments/wechat/notify` | 后续能力：接入商户号后校验签名并幂等处理微信回调；首期禁用 |
| 退款 | POST | `/api/refunds` | 创建整单或子订单退款申请 |
| 消息 | GET | `/api/inbox/messages` | 查询站内消息和节日卡片 |
| 消息 | POST | `/api/inbox/messages/{messageId}/read` | 将当前用户自己的消息标记为已读 |
| 消息 | POST | `/api/admin/inbox/messages` | 管理员发送站内消息 |
| 小票 | GET | `/api/orders/{orderId}/receipt` | 获取订单电子小票快照 |
| 配送 | GET | `/api/delivery/tasks` | 配送员任务列表 |
| 管理 | POST | `/api/admin/delivery-tasks/{taskId}/assign` | 管理员按区域派单 |
| 商家 | PUT | `/api/merchant/skus/{skuId}/stock` | 调整库存并记录原因 |
| 商家 | POST | `/api/merchant/applications` | 消费者提交商家入驻申请 |
| 商家商品 | POST | `/api/merchant/catalog/warehouses` | 创建商家仓库，必须绑定启用的固定配送区域 |
| 商家商品 | POST | `/api/merchant/catalog/warehouse-categories` | 设置仓库可经营分类 |
| 商家商品 | POST | `/api/merchant/catalog/warehouse-rules` | 设置商品分类的商家仓配规则与优先级 |
| 商家商品 | POST | `/api/merchant/catalog/products` | 创建按重量计价商品草稿，校验商家价不得高于市场价 5% |
| 商家商品 | PUT | `/api/merchant/catalog/products/{productId}/publish` | 仅存在启用的分类仓配规则时允许上架 |
| 商家商品 | POST | `/api/merchant/catalog/batches` | 批次入库，需匹配商品所属商家、仓库分类和仓配规则 |
| 商家商品 | GET | `/api/merchant/catalog/products` | 查询当前商家的商品和可用库存 |
| 商家 | GET | `/api/merchant/dashboard` | 首期经营数据看板，返回固定统计口径的销售、订单、库存和履约指标 |
| 商家 | GET | `/api/merchant/settlements` | 查询已送达订单的佣金结算记录 |
| 商家营销 | POST | `/api/merchant/marketing/promotions` | 创建可叠加的优惠券、满减、会员、积分或秒杀规则 |
| 商家营销 | POST | `/api/merchant/marketing/flash-sales` | 创建商品级秒杀活动，配置秒杀价、总克数和单用户限购 |
| AI | POST | `/api/ai/conversations/{id}/messages` | AI 对话，工具调用受白名单控制 |
| 管理 | GET | `/api/admin/dashboard` | 销售、库存和履约指标 |
| 管理 | GET | `/api/admin/platform-rules` | 查看配送费、库存预占、称重误差等平台规则 |
| 管理 | PUT | `/api/admin/platform-rules/{ruleKey}` | 修改平台规则并记录操作人和变更时间 |
| 管理 | GET | `/api/admin/marketing/batch-promotions/candidates` | 按临期天数规则查询可售批次促销候选 |
| 管理 | POST | `/api/admin/marketing/batch-promotions` | 确认指定批次低价促销排期，禁止过期后结束和时间重叠 |
| 管理 | GET | `/api/admin/refund-policies` | 查看水果、蔬菜等商品售后时限 |
| 管理 | PUT | `/api/admin/refund-policies/{scope}` | 修改售后窗口和举证要求 |
| 管理 | GET | `/api/admin/merchants/applications` | 审核商家入驻申请 |
| 管理 | PUT | `/api/admin/merchants/{merchantId}/review` | 通过或驳回商家入驻 |
| 管理 | POST | `/api/admin/categories` | 创建商品分类 |
| 管理 | GET | `/api/admin/commissions` | 查询平台佣金与商家结算 |
| 管理 | POST | `/api/admin/commissions/generate` | 为尚未结算的已送达子订单生成佣金结算单 |
| 管理 | POST | `/api/admin/delivery-zones` | 创建固定配送区域 |
| 管理 | GET | `/api/admin/delivery-zones` | 查询固定配送区域 |
| 管理 | PUT | `/api/admin/delivery-zones/{zoneId}` | 修改或停用固定配送区域 |
| 配送 | PUT | `/api/delivery/tasks/{taskId}/accept` | 骑手接单，超时后任务转回派单池 |
| 配送 | PUT | `/api/delivery/tasks/{taskId}/pick` | 骑手确认取货 |
| 配送 | PUT | `/api/delivery/tasks/{taskId}/deliver` | 骑手上传送达凭证并完成任务 |
| 配送 | GET | `/api/delivery/performance` | 查询骑手接单率、超时率、准时率 |
| 售后 | POST | `/api/refunds` | 仅缺货/品质问题，需图片和描述，送达后一天内申请 |
| AI | POST | `/api/ai/assistant/messages` | 消费者 AI 导购或本人订单查询，工具范围固定且无跨账户数据 |
| AI | POST | `/api/admin/ai/holiday-cards` | 管理员生成并发送受限文本的节日 SVG 卡片站内消息 |
| 开放 API | GET | `/open-api/v1/products` | HMAC 签名客户端查询商品，支持商家边界 |
| 开放 API | GET | `/open-api/v1/inventory` | HMAC 签名客户端按商家边界查询库存 |
| 开放 API | GET | `/open-api/v1/orders/{orderNo}` | HMAC 签名客户端查询订单 |
| 开放 API | GET | `/open-api/v1/orders/{orderNo}/receipt` | HMAC 签名客户端查询电子小票 |
| 开放 API | GET | `/open-api/v1/orders/{orderNo}/traceability` | HMAC 签名客户端查询批次追溯信息 |
