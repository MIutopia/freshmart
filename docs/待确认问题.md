# 待确认问题

首期规则已经确认，以下内容作为实现约束；剩余问题只涉及默认参数，不阻塞网页端 MVP。市场价、商家价、用户支付价、平台补贴和佣金计提口径以 `docs/价格与仓配结算规则.md` 为准。

## 已确认的 P0 规则

1. 多商家入驻审核，平台抽取佣金并生成结算记录。
2. 配送范围固定区域，平台自有配送员统一派单。
3. 支付支持余额和个人微信收款码；个人收款码仅允许管理员人工确认的本地测试流程，不接入商户号回调。
4. 商品按重量计价，商家价不得超过市场价 5%，差额由平台承担。
5. 下单预占库存，15 分钟未支付释放。
6. 售后仅支持缺货/品质问题，送达后一天内申请，图片加描述；运输损坏仅可作为品质问题证据，由客服和 AI 辅助审核。
7. 个人收款码资金状态只能由运营/财务通过受控后台接口变更；技术人员无资金状态变更权限，所有变更写入状态日志。

## 已确认的 P1 规则

1. 首期使用纯账号密码；商家端跳转独立页面。
2. 配送员为平台自有，支持派单、接单超时和绩效统计。
3. AI 首期实现导购和订单查询，使用 DeepSeek API 生成受控文案；商家端首期仅提供经营数据看板，AI 经营分析后续开发。
4. 支持优惠券、满减、会员等级、积分和秒杀，优惠允许叠加。

## 已确认的 P2 范围

1. 支持多仓库；同一商家子订单不允许跨仓、跨区域拆单；不同商家仓库严格隔离。
2. 支持电子小票、批次追溯和临期低价促销；仓库必须配置可经营分类，商家必须配置商品分类仓配规则。
3. 支持开放 API；暂不建设小程序和 App。
4. 日订单量目标 50 单、并发用户 20 人；图片和视频单文件上限 30 MB。

## 当前待定的非阻塞参数

- 配送费默认满 59 元免配送、否则 6 元，后台可修改。
- 平台默认佣金比例 10%，后台可修改。
- 当前只建设网页端，不建设小程序和 App。
