# 待确认问题

首期规则已经确认，以下内容作为实现约束；剩余问题只涉及默认参数，不阻塞网页端 MVP。

## 已确认的 P0 规则

1. 多商家入驻审核，平台抽取佣金并生成结算记录。
2. 配送范围固定区域，平台自有配送员统一派单。
3. 支付支持余额和微信 Native 扫码；本地测试暂不接商户号和域名回调。
4. 商品按重量计价，商家价不得超过市场价 5%，差额由平台承担。
5. 下单预占库存，15 分钟未支付释放。
6. 售后仅支持缺货/品质问题，送达后一天内申请，图片加描述，由客服和 AI 辅助审核。

## 已确认的 P1 规则

1. 首期使用纯账号密码；商家端跳转独立页面。
2. 配送员为平台自有，支持派单、接单超时和绩效统计。
3. AI 首期实现导购和订单查询。
4. 支持优惠券、满减、会员等级、积分和秒杀，优惠允许叠加。

## P2：后续增强

1. 是否需要多仓库、区域库存和跨仓拆单？
2. 是否需要发票、电子小票、批次追溯和临期促销？
3. 是否需要开放 API、小程序端或 App 端？
4. 预计日订单量、并发用户量和图片/视频存储量级是多少？

## 当前待定的非阻塞参数

- 配送费默认满 59 元免配送、否则 6 元，后台可修改。
- 平台默认佣金比例 10%，后台可修改。
- 当前只建设网页端，不建设小程序和 App。
