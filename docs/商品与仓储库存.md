# 商品与仓储库存

商品、仓库和库存数据由 `freshmart_merchant` 管理。用户端只读取状态为 `ACTIVE` 的商品；商家新建商品默认为 `DRAFT`，不得绕过仓配规则直接上架。

## 上架与入库约束

1. 管理员先创建商品分类。
2. 商家创建并绑定一个启用的固定配送区域仓库。
3. 商家为仓库开启可经营分类。
4. 商家为该分类配置仓配规则和优先级。
5. 商家创建商品时填写市场价与商家价；商家价最高为市场价的 105%。
6. 仅当存在启用的仓库可经营分类与分类仓配规则时，商品可上架，批次可入库。

商品、仓库、批次必须属于同一个商家。批次入库会拒绝跨商家商品、非本商家仓库或未配置的商品分类，保障后续订单不跨商家、跨仓库或跨区域拆分。

## 本地联调顺序

1. 使用 `admin-test-01` 登录，创建商品分类。
2. 在 `freshmart_delivery.delivery_zones` 中创建一个 `ACTIVE` 配送区域，配送区域管理接口将在配送模块提供。
3. 使用 `merchant-test-01` 登录，依次创建仓库、仓库可经营分类、分类仓配规则、商品和库存批次。
4. 调用商品上架接口，再访问 `GET /api/catalog/products` 检查用户端商品列表。
