## 四、字段字典

完整的字段级说明可直接查询数据库注释（`information_schema.COLUMNS.COLUMN_COMMENT`），或使用下面的语句按表查看：

```sql
SELECT COLUMN_NAME AS 字段, COLUMN_TYPE AS 类型,
       IF(IS_NULLABLE = 'NO', '否', '是') AS 可空,
       COLUMN_COMMENT AS 说明
FROM information_schema.COLUMNS
WHERE TABLE_SCHEMA = 'freshmart_trade' AND TABLE_NAME = 'orders'
ORDER BY ORDINAL_POSITION;
```

五个业务域库的字段注释已 100% 覆盖，因此上述查询对任意卫星库表都能返回完整中文说明。主库的 42 张历史遗留表只补齐了表注释（并标注现行归属），未逐列补注释。

## 五、维护约定

1. **新增表或字段时必须写中文注释**，否则本文档与界面字典都会出现空白项。Flyway 迁移中建表时直接用 `COMMENT` 声明。
2. **修改已有字段注释**要用 `MODIFY COLUMN` 重述完整定义（MySQL 没有单独改注释的语法），改完必须比对执行前后的列结构快照，确认类型、可空性与默认值未变。
3. **新增业务枚举时**，同步在 `frontend/src/constants/dictionaries.ts` 增加中文映射，避免界面回退显示英文原值。
4. **主库遗留表**不再新增写入；清理前先确认没有历史数据查询需求。
